# ABTalks 60-Day Challenge - Technical Design & Implementation

This document serves as the implementation guide and architectural blueprint for the ABTalks 60-Day Challenge redesign. 

## 1. Stack & Design Philosophy
*   **Framework:** Next.js (App Router)
*   **Styling:** Tailwind CSS
*   **Aesthetic:** Minimalist Luxury (Dark Mode). Deep true blacks, stark whites, refined typography (tracking-tight), and subtle zinc borders.
*   **Key Feature ("Thoughtful Idea"):** "Daily Insight" field forces students to reflect on their learning, compiling into an exportable 60-Day Journal at the end of the challenge.

## 2. File Structure Needed
*   `app/globals.css`
*   `app/layout.tsx`
*   `app/page.tsx`
*   `app/dashboard/page.tsx`
*   `app/day/[id]/page.tsx`
*   `lib/mockData.ts`
*   `tailwind.config.ts`

## 3. Implementation Strategy

### A. Mock Data Setup
Create a mock data file defining a user object (name, avatar URL, current streak, total completed) and a challenge day object (day number, title, description, list of deliverables, completion status).

### B. Global Layout Design
Set up a dark mode layout that constrains the main view to a maximum width of 390px. This enforces a mobile-first viewport even on desktop screens, centering the content with subtle, dark zinc borders.

### C. Landing Page (/)
Design a high-trust, minimalist entry point. Include:
*   A stark, monochromatic logo.
*   A clear, bold value proposition ("60 Days. Prove your potential.").
*   A simple 3-step breakdown (Build, Ship, Grow).
*   A prominent, high-contrast call-to-action button to commit to the challenge.

### D. Student Dashboard (/dashboard)
Display the user's current status and next actions. Include:
*   A large, minimal stat card for the current streak and completion progress bar.
*   A clear link to "Today's Mission".
*   A 60-day visual heatmap/grid showing completed days (white), the current day (outlined), missed days (subtle red edge case), and locked upcoming days (dimmed).

### E. Challenge Day (/day/12)
Provide extremely clear instructions for the daily task. Include:
*   Sticky top navigation for late-night mobile scrolling.
*   The task description and a bulleted list of deliverables.
*   A submission form requiring a GitHub URL and a LinkedIn Post URL.
*   A mandatory "Daily Insight" text area to capture the student's primary learning or struggle.
*   A fixed, floating action bar at the bottom to submit the proof of work.

### F. Tailwind Configuration Requirements
Configure Tailwind to utilize the zinc color palette and add custom letter-spacing utilities (`-0.02em` and `-0.04em`) to achieve the tight, luxury typography aesthetic.
